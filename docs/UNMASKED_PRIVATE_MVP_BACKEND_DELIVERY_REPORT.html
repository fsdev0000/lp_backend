1. Identification of Reusable Components in lp_backend High-Leverage Assets

Rather than building new subsystems from scratch, this implementation leverages our battle-tested services and database patterns already active in production:

API
Backend & API Framework
  • Express 5 + TypeScript: Standardized routing, controller patterns, and centralized error handling (src/api/routes).
  • Zod Validation Engine: Direct reuse of schema validation patterns from src/api/routes/consent.ts to enforce strict typing, sanitize inputs, and return structured field-level 400 Bad Request arrays.
  • Rate Limiting & Abuse Prevention: Pre-configured express-rate-limit middleware in src/middleware/rateLimiter.ts (e.g., contactRateLimiter).
  • Privacy-Preserving IP Hashing: Reusing the SHA-256 IP anonymization method in consent.ts for compliance tracking.
DB
Database & Persistence Layer
  • Prisma ORM + PostgreSQL: Existing active connection pool using DATABASE_URL and DIRECT_URL in prisma/schema.prisma.
  • Consent Audit Architecture: Direct architectural reuse of the ConsentAuditLog pattern (version logging, user-agent truncation, timestamping).
  • Idempotency & Duplicate Locking: Reusing the unique constraint / idempotency key pattern from ConsentAuditLog and email indexing to block repeated identical submissions.
  • Structured Audit Logging: Utilizing the existing SystemLog table for persistence of application processing and dispatch events.
EM
Email & Notification Services
  • Core Email Utilities (src/services/email.ts): Pre-built escapeHtml() for XSS safety, formatOperationalSubmissionDate() for Dubai GST timezone formatting, and renderTemplate().
  • GoHighLevel Messaging API (src/services/ghl.ts): Working integration for sendEmail() and upsertContact() using location credentials.
  • Executive Briefing Template: Pre-built HTML notification in src/api/routes/contact.ts (lines 195–253) styled for Lionel (Navy `#1a1a1a`, Gold `#C49A45`, Cream `#F9F7F2`) can be directly repurposed for instant qualified alerts.
